# YouTube-Transcript-Summarizer
The YouTube Transcript Summarizer is a web-based application that extracts transcripts from YouTube videos and generates concise summaries using Natural Language Processing (NLP). This tool allows users to quickly understand the key points of a video without watching the entire content.
Features:
Extracts Transcripts – Fetches video subtitles from YouTube using youtube_transcript_api.
AI-Powered Summarization – Uses Hugging Face's DistilBART model to generate concise summaries.
Web Interface – Simple Flask-based UI for easy input and output display.
Fast Processing – Handles large transcripts efficiently by segmenting text.
